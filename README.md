## About Me

I'm a microbiology and biochemistry student who fell in love with the *data* side of science — the patterns, the modeling, the "why does this trend exist" questions that a wet lab can't always answer fast enough. I'm now building a self-taught path into data science and machine learning, with a long-term interest in bioinformatics and health-tech, where I can combine my domain background with statistical and ML tooling.

I learn in public: most of my repos are structured, documented study projects rather than one-off scripts — I treat each one as something a stranger (or a future me) should be able to open and understand without asking questions.

- 🔬 Domain background: microbiology & biochemistry
- 📊 Currently building: portfolio-grade data analysis projects in Python
- 🧠 Studying: Machine Learning A-Z (own bilingual study guides, see pinned repo)
- 🗺️ Following a self-built roadmap toward AWS certifications + a bioinformatics/health-tech specialization
- 💬 Ask me about: exploratory data analysis, data cleaning at scale, or turning a science background into a data career

An end-to-end EDA on a **7.46M-record, 1.64M-athlete** public ultra-marathon dataset (1798–2022). Investigates whether human endurance performance is still improving, what the true peak age for endurance sport is, and how repeat athletes trend across their careers.
`Python` `Pandas` `NumPy` `Matplotlib` `EDA` `Data Cleaning`

### 🧭 [Data Science Learning Roadmap](#)
